Install

Requires macOS on Apple Silicon. For the free local model, install Ollama and pull qwen3.5:4b-mlx.

  1. Download the DMG, open it and drag Vakyartha to Applications.
  2. Builds are not yet signed with an Apple Developer ID. On first launch, open System Settings → Privacy & Security and choose Open Anyway.
  3. Choose a model in the composer and ask for something you can use: a plan, a comparison, a dashboard.

Verify your download

Every release carries checksums and a release record signed with the owner's Ed25519 key. Put all of a release's files in one folder, then:

  1. Check every file against its checksum:
    shasum -a 256 -c SHA256SUMS.txt
  2. Check the owner's signature on the release record (OpenSSL 3):
    xxd -r -p runtime-manifest.json.sig > record.sig
openssl pkeyutl -verify -pubin -inkey release.pem -rawin -in runtime-manifest.json -sigfile record.sig
    Or, with Node.js 22+, run node scripts/verify.ts <folder> <tag> from the releases repository.
