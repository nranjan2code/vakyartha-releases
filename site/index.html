Install

macOS on Apple Silicon. Use a free local model through a local model runner, or a hosted model with your own key.

  1. Download and move

    Open the DMG and drag Vakyartha to Applications.

  2. Allow it once

    On first launch, open System Settings, Privacy & Security, and choose Open Anyway. Builds are not yet notarized by Apple.

  3. Ask for something

    A plan, a comparison, a dashboard. The answer arrives as something you can use.

Verify

Each release carries checksums and a release record signed with the owner's key. Keep a release's files in one folder.

  1. Checksums

    Every file matches its SHA-256.

    shasum -a 256 -c SHA256SUMS.txt
  2. Signature

    The release record carries the owner's Ed25519 signature (OpenSSL 3).

    xxd -r -p runtime-manifest.json.sig > record.sig
openssl pkeyutl -verify -pubin \
  -inkey release.pem -rawin \
  -in runtime-manifest.json -sigfile record.sig
  3. Release key

    release.pem · release.pub
